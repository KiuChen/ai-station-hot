# 北京场馆与高校目录

入口：艺术频道 → 国内看展 → 北京场馆与高校（`/art/exhibitions/venues`）。

2026-10-25 整理 318 个场馆，其中 113 个高校场馆，涉及 65 所学校。支持馆名、别名、地址、高校和展陈方向检索，以及区县、类型、高校、方向筛选与分页。目录只读取发布资料，不采集、不调用模型。

覆盖基线为北京市文物局备案馆名录 203 项、北京旅游网地点目录 1,448 项（包括景区等，并非 1,448 家博物馆）、高校 29 馆介绍、首都教育 43 项开放资源清单及教育部北京 92 所普通高校名单。逐项筛选艺术、工艺、建筑、设计、影视表演、文学和综合文博机构；高校实体展馆另含自然、科技与校史。高校逐校核对结果见 `beijing-university-venue-audit.json`。27 所学校暂未确认实体馆，不能据此判断没有展馆。

实验室、培训基地、纯线上数字馆、外省校区不充当北京实体馆。木木美术馆采用朝阳门内大街81号新址；央美术馆 YAM 与中央美术学院美术馆分别收录；旧名合并检索。

这是可追溯的公开资料目录，不能保证覆盖未公开机构、未备案空间及全部商业画廊。每项均保留来源链接、资料核对日期和开放待核对提示。旧文章只证明实体空间有公开记录，不代表今日开放；往年暑期进校安排不沿用。官方地点目录部分详情请求受到限流，仅能核对列表的项目保留官方目录出处，不伪称馆方已确认。

场馆目录与展览动态分开。只有已实际接入采集的机构显示“本站展览”，其他场馆可跳转官方资料或官网查展；不生成虚构展期，不把常设场馆冒充正在举办的特展。原有国博、故宫、上博展览采集继续运行。

修改目录请编辑 `industry/profiles/art/exhibition-venues.json`，补充官方来源，合并别名并校验高校归属。每次发布前执行仓库要求的全量检查。
