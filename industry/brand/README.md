# AI Station 品牌资源

已确认的「折页 S」图标以展开的纸页隐含 Station 的首字母，采用米白与冰青配色。

- source/folded-s.png：内置图像生成工具生成并经使用者确认的原始设计。
- icon.png：512 × 512；icon-192.png：192 × 192；apple-icon.png：180 × 180。
- favicon.ico：16、32、48、64、256 像素多尺寸图标。
- logo.svg：封装同一 PNG 设计的 SVG 入口，非描摹矢量版本。

导航、手机首页和后台登录页通过共享 Wordmark 使用同一图标。

设计提示：极简编辑品牌，抽象折页 ribbon 隐含 S，米白主体、冰青折面、深色圆角底，留白充足，轮廓清晰，未来感通过几何比例表达。
